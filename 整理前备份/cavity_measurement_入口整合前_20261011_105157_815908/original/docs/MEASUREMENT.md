# A 内边框尺寸测量

2026-10-11 更新：默认单图入口在识别 A 内边框后继续计算像素长宽。用户目前没有实际标定数据，因此实拍结果使用 `px`，不生成毫米尺寸。

## 使用

- 单图：把 BMP 等图片拖到根目录 `measure_image.cmd`；比例提示直接回车。
- 批量：双击根目录 `measure_folder.cmd`，默认读取程序父目录的 `图片` 文件夹；也可以把其他图片文件夹拖到它上面。默认不询问比例，直接输出像素尺寸。
- 单图输出仍在指定的 `图片检测结果/时间戳`。
- 批量输出在 `图片检测结果/尺寸测量/时间戳`，包含 `尺寸汇总.csv`、`summary.json`、`尺寸测量总览.jpg`，以及每张图片对应的子文件夹。

单图文件夹内，`尺寸结果.txt` 给出中文结果，`dimensions.csv` 给出数值，`result.json` 保留全部诊断，`overlay_preview.jpg` 便于查看。`contour_points.csv` 是完整轮廓，`edge_points.csv` 是参与直边拟合的点及内点标记；没有标定时，两个 CSV 的毫米坐标均留空。

```powershell
# 在程序根目录运行；默认测量 A 内边框长宽
python cavity_measure.py measure --image "..\图片\矩形腔体1.bmp"
python tools/measure_folder.py

# 只识别轮廓，不测尺寸；原四图回归仍使用此模式
python cavity_measure.py measure --image "..\图片\矩形腔体1.bmp" --detection outline
python tools/verify_baseline.py

# 使用修改后的尺寸质量门限；这会改变拒测标准，不等于提高精度
python cavity_measure.py measure --image "..\图片\矩形腔体1.bmp" --measurement-config config/contour_measurement.example.json
```

## 测的是什么

先跟踪用户确认的 A：外围黑色边界带靠腔内的一沿。闭合轮廓与圆角保留，但直边拟合只使用各边中间的 56% 区域，即排除两端各 22%；其中没有直接灰度支持的点不参与拟合。

最小面积包围矩形仅用于分组和排除圆角，**其宽高不是输出尺寸**。四条直边分别经过 RANSAC 初始化、有限幅度的 MAD 离群点剔除、TLS 拟合；没有强制平行、垂直或共享方向。尺寸取对边法向平分方向上中央截面的间距，较大值称长度，较小值称宽度。JSON 同时保留 25%、50%、75% 位置的截面间距及夹角，便于发现透视或形状变化。

绿色是完整轮廓，黄色轮廓段表示原灰度支持不足；青色直线是参与测量的直边区段，橙黄色双箭头表示中央截面的长宽。直线外推交点是虚拟尖角，不能解释为圆角的实体角点。

## 质量检查与状态

默认每边至少 15 个受支持点，直接支持比例至少 95%，拟合内点比例至少 80%，中段覆盖至少 85%，最大内点空缺不超过中段的 15%。剔除阈值由残差 MAD 计算并限制在 1–4 px；内点 RMS 不超过 1.5 px，全部受支持点的 RMS 不超过 2 px、绝对残差第 95 百分位不超过 4 px。对边夹角不超过 0.20°，相邻边偏离直角不超过 0.50°。

这些是图像处理质量门限，**不是零件公差或测量不确定度**。全部受支持点的残差也受检查，避免仅选择少量贴近直线的点而掩盖边界起伏。

| 状态 | 含义 |
| --- | --- |
| `pixel_only` | 检查通过，输出图像上的像素长宽 |
| `measured` | 检查通过，并按用户提供的独立标定计算毫米值 |
| `review_required` | 轮廓仍保留，但拟合、覆盖或几何检查不通过；`dimensions` 留空 |
| `contour_detected` | 显式使用 `outline`，仅识别轮廓 |
| `failed` | 图像、参数或完整目标轮廓不可用 |

默认 `auto` 和显式 `contour` 都测量选定轮廓；识别或尺寸检查失败时不会自动转测其他区域。旧灰度区域流程仍可通过 `--detection strict` 调用；`--corners`、`--config`、`--polarity`、`--band-px` 属于旧流程，需要明确选择 `strict`。

## 当前实拍结果与限制

原四张基准图的像素长宽已计算。目录中的第 5、6 张图也会处理；在当前门限下，下边界等区段的残差较大，输出 `review_required`，不把不稳定的直线拟合值当作通过检查的长宽。局部放大图可见灰度边界起伏和纹理干扰，这不足以区分实物形状变化与光学成像偏差。

像素尺寸属于图像平面上的表观几何量。缺少标定和独立尺寸真值时，不能判断零件实际长度、宽度、加工精度或是否合格；不同照片间数值相近也不能证明重复测量精度。圆角半径、腔深和侧壁厚度不在本次测量范围。

以后需要毫米值时，应使用 A 边界所在底面平面的独立标准器进行标定。标量毫米/像素比例不能纠正透视，平面单应矩阵不能自动消除镜头畸变；标定板放在工件上表面与腔体底面存在高度差时，也可能引入比例误差。已有 `--mm-per-pixel`、`--calibration` 接口可使用可靠标定数据，不应填入示例值或用被测件设计尺寸自我验证。
